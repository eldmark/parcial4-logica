# Declaración de uso de inteligencia artificial

En el desarrollo de este proyecto se utilizaron las siguientes herramientas de inteligencia artificial como fuente de consulta y apoyo para programar, revisar y documentar:

- Claude Code (Anthropic), con el modelo Claude Opus 5.5, se usó para modelar esta copia del proyecto y para adaptar la interfaz para que sea responsive y más cómoda de usar (Anthropic, 2026).
- Codex (OpenAI) se usó como apoyo en el motor de simulación y la API HTTP (OpenAI, 2026).

El proyecto original lo desarrollamos para Teoría de la Computación Marco Alejandro Díaz Castañeda ([@eldmark](https://github.com/eldmark)), Jackelyn Nicolle Girón Villacinda ([@gnicoool](https://github.com/gnicoool)) y Sergio Estuardo Tan Coromac ([@stan-2021131](https://github.com/stan-2021131)).
